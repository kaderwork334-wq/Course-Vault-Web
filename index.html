প্রথমবার সেটাপ করতে তোমার নিজের Google Cloud OAuth Client ID লাগবে — এটা একবারই দিতে হবে, তোমার ব্রাউজারে সেভ থাকবে।

Client ID কোথায় পাবে জানো না? নিচে ধাপে ধাপে গাইড দেওয়া আছে (README দ্রষ্টব্য)। সংক্ষেপে: Google Cloud Console → নতুন প্রজেক্ট → Google Drive API চালু করো → OAuth Client ID (Web application) বানাও → এই পেজের ঠিকানাটা Authorized JavaScript origins-এ যোগ করো।
